# @wavemaker/wmx-rn-components

WaveMaker Studio (WMX) widget wrappers and metadata for the `@wavemaker/rn-*` React Native component packages.

## Layout

| Path | Purpose |
|------|---------|
| `components/<widget>/` | Studio wrappers, `wmx.json` metadata, icons, and assets |
| `scripts/generate-wmx.js` | Generates the publishable WMX bundle |
| `dist/` | Generated output |

## Generate

```bash
npm install
npm run generate:wmx
```
